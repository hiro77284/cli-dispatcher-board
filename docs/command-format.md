# コマンド定義ファイルの書き方

`commands/` フォルダ（サブフォルダも可）に置いた `.yaml` / `.yml` を読み込みます。保存すると自動で読み直します。
名前が `_` か `.` で始まるファイル・フォルダは読み込みません（下書きの置き場に使えます）。

1 ファイルに 1 コマンドを書くか、`commands:` の下に複数並べます。

```yaml
commands:
  - id: ping
    name: Ping 疎通確認
    ...
  - id: tracert
    ...
```

## コマンドの項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | | 一意な名前。省略するとファイル名（複数あるときはファイル名-番号） |
| `name` | | 一覧に出す名前 |
| `category` | | 一覧のまとまり。省略すると「その他」 |
| `description` | | 画面に出す説明。改行はそのまま表示 |
| `program` | ○ | 実行するプログラム（`ffmpeg`、`C:\Tools\x.exe` など）。`{{param}}` も使える |
| `shell` | | `none`（既定）/ `cmd` / `powershell`。下の「シェル」を参照 |
| `params` | | 入力欄の定義（下記） |
| `args` | | 引数の並び（下記） |
| `cwd` | | 作業フォルダ。`{{repo}}` のように入力値を使える。省略するとホームフォルダ |
| `env` | | 追加の環境変数（`KEY: 値`）。値に `{{param}}` を使える |
| `confirm` | | 書くと、実行前にこの文で確認ダイアログを出す（削除・上書きを伴うコマンド向け） |
| `tags` | | 検索用のキーワード（配列） |

## パラメータ（`params`）

| 項目 | 内容 |
|---|---|
| `name` | 半角英数字・`_`・`-`。`args` から `{{name}}` で参照する |
| `label` | 画面に出す名前 |
| `type` | `text`（既定）/ `number` / `select` / `flag` / `file` / `folder` |
| `description` | 入力欄の下に出す説明 |
| `required` | `true` なら空のとき実行できない |
| `default` | 既定値 |
| `placeholder` | 空欄のときに薄く出す例 |
| `options` | `select` の選択肢。`[a, b]` か `[{ value: a, label: 表示名 }]` |
| `allowCustom` | `select` で一覧にない値も入力できるようにする |
| `min` / `max` | `number` の範囲 |
| `save` | `file` で「保存先を選ぶ」ダイアログにする |
| `filters` | `file` のダイアログの種類 `[{ name: 動画, extensions: [mp4, mkv] }]` |
| `split` | `text` で、空白区切りの複数の引数として渡す（`"..."` で囲める）。追加オプション欄向け |
| `pattern` | 入力値をチェックする正規表現 |

入力した値はコマンドごとに保存され、次に開いたときに戻ります（「既定値に戻す」で初期化）。

## 引数（`args`）

上から順に並べたものがそのまま引数になります。空白を含む値の引用は自動で行うので、`"` で囲む必要はありません。

```yaml
args:
  - -i                      # そのままの文字列
  - "{{input}}"             # 入力値に置き換え
  - "/MT:{{threads}}"       # 文字列の一部に埋め込み
  - if: overwrite           # 条件付き：overwrite が有効（空でない）なら中の引数を足す
    args: ["-y"]
  - if: preset              # equals：値が一致したときだけ
    equals: slow
    args: ["-preset", "slow"]
  - if: forever             # not: true で条件を反転
    not: true
    args: ["-n", "{{count}}"]
  - raw: "| sort"           # 引用せずにそのまま入れる（shell: cmd / powershell のときだけ）
```

- 引数の中で参照しているパラメータが空なら、**その引数は丸ごと省かれます**（例：`"--author={{author}}"` は作者が空なら付かない）。
- `flag` は、オンのとき「空でない」扱いです。`if:` と組み合わせて使います。
- `if` は入れ子にできます。

## シェル

| `shell` | 動き | 使いどころ |
|---|---|---|
| `none` | プログラムを直接起動。`.cmd` / `.bat`（`npm` など）は自動で `cmd.exe` 経由にする | ほとんどの場合 |
| `cmd` | `cmd.exe /d /s /c "…"` で実行 | `dir`・`copy` などの組み込みコマンド、パイプやリダイレクト（`raw`） |
| `powershell` | `pwsh`（無ければ Windows PowerShell）で実行。スクリプトは `-EncodedCommand` で渡す | コマンドレット、パイプライン |

出力は疑似端末（ConPTY）を通して受け取るので、進捗バー・色・文字化けのない日本語がそのまま表示されます。実行中は出力欄に直接キー入力できます（`y/n` の確認、`Ctrl+C` での割り込みなど）。
